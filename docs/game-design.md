# 막대 길막 보드게임 기획서

두 플레이어가 보드 양 끝에서 출발해 상대편 끝 줄에 먼저 도착하면 이기는 게임이다. 각 플레이어는 자기 턴에 말을 움직이거나 막대를 설치해 상대의 경로를 막을 수 있다.

기본 구조는 보드게임 쿼리도(Quoridor, 1997)와 같다. 검증된 규칙을 기반으로 하고 차별화 요소를 추가하는 방향으로 진행한다.

---

## 1. 핵심 규칙

### 보드

- 9×9 칸으로 구성한다.
- 말은 칸 위에, 막대는 칸과 칸 사이의 홈에 놓는다.
- 교차점에 두는 방식보다 "칸 + 홈" 구조가 막대 판정을 단순하게 만든다.

### 시작과 승리

- 플레이어 A는 아래쪽 가운데(e1), 플레이어 B는 위쪽 가운데(e9)에서 시작한다.
- 상대편 끝 줄의 아무 칸에나 먼저 도착하면 승리한다.

### 턴 행동

한 턴에 다음 두 행동 중 하나만 할 수 있다.

1. 말을 상하좌우로 1칸 이동
2. 막대 1개 설치

### 막대 규칙

- 길이는 2칸이며, 가로 또는 세로로 설치한다.
- 플레이어당 10개로 제한한다.
- 다른 막대와 겹치거나 십자로 교차할 수 없다.
- 어느 플레이어든 목표 줄까지 가는 경로를 완전히 막으면 안 된다. 이 규칙이 없으면 게임이 성립하지 않는다.

### 점프 규칙

- 두 말이 마주 보면 상대 말을 뛰어넘을 수 있다.
- 상대 말 뒤가 막대나 보드 끝으로 막혀 있으면 대각선으로 이동한다.
- 이 규칙이 없으면 두 말이 서로 막혀 교착 상태가 생긴다.

---

## 2. 구현 핵심 로직

| 항목 | 방법 |
|---|---|
| 보드 상태 | 말 위치 2개, 가로 막대 배열 8×8, 세로 막대 배열 8×8 |
| 이동 가능 여부 | 두 칸 사이에 막대가 있는지 검사하는 함수 하나로 통일 |
| 막대 설치 검증 | 임시로 설치한 뒤 양쪽 플레이어 모두 BFS로 목표 줄 도달 가능 여부 확인, 불가능하면 취소 |
| 점프 처리 | 이동 후보 생성 시 상대 말 위치를 특수 처리 |
| 승리 판정 | 이동 직후 행 번호 확인 |

막대 설치 검증이 가장 까다롭고 버그가 많이 나는 부분이므로 이 함수부터 단위 테스트를 작성한다.

---

## 3. 웹 구조

### 프론트엔드

- React + SVG 또는 Canvas를 사용한다.
- 9×9 규모에서는 SVG가 클릭 판정과 hover 미리보기 구현에 유리하다.

### 게임 로직

- 순수 TypeScript 모듈로 분리한다.
- UI, 서버, AI가 동일한 로직을 공유한다.

### 멀티플레이

- 1차: 한 화면에서 번갈아 두는 로컬 2인 모드
- 2차: WebSocket(Socket.IO 또는 FastAPI WebSocket) 기반 방 코드 온라인 대전
- 온라인 모드에서는 서버에서 수를 다시 검증해 조작을 방지한다.

### AI 상대

- 평가 함수: 상대 최단 경로 길이 − 내 최단 경로 길이
- 미니맥스 + 알파베타 가지치기, 깊이 2~3에서도 충분히 강하다.
- 이후 MCTS나 강화학습으로 확장할 수 있다.

---

## 4. UX 요소

- 마우스 hover 시 막대 미리보기 표시, 설치 불가능한 위치는 빨간색으로 표시
- 내 말이 이동 가능한 칸 하이라이트
- 양쪽 플레이어의 현재 최단 경로 길이 표시 옵션 (전략 파악 및 디버깅용)
- 남은 막대 개수, 현재 턴 표시
- 무르기, 기보 저장

---

## 5. 차별화 아이디어 (선택)

- **다양한 막대 종류**: 3칸짜리 긴 막대, 몇 턴 뒤 사라지는 임시 막대, 상대 막대 하나를 제거하는 도구
- **4인 모드**: 네 변에서 각자 반대편으로 이동, 막대는 1인당 5개
- **안개 모드**: 상대가 설치한 막대가 일정 턴 동안 보이지 않음
- **보드 크기 선택**: 7×7 빠른 대전, 11×11 장기전

---

## 6. 개발 순서

5장 중 **다양한 막대 종류**는 선택이 아니라 핵심 규칙으로 채택했다. 구현 기준 규칙은 [rules.md](rules.md)에 정리한다. 나머지 아이디어는 세그먼트 5에서 확장한다.

작업은 아래 세그먼트 단위로 나눠 진행하고, 세그먼트 하나를 마칠 때마다 확인한 뒤 다음으로 넘어간다.

### 세그먼트 1: 게임 로직 모듈 + 테스트 ✅

- `shared/game/`에 순수 TypeScript로 작성 (UI, 서버, AI가 공유)
- 이동, 점프, 막대 설치와 BFS 경로 검증, 임시 막대, 철거 도구, 승리 판정
- 상태를 바꾸지 않고 새 상태를 돌려주는 구조 (무르기 대비)
- `node:test` 단위 테스트, 막대 설치 검증 중심

### 세그먼트 2: 로컬 2인 UI ✅

- React에서 `shared/game` 모듈 연결
- SVG로 보드, 말, 막대 그리기
- 이동 가능한 칸 하이라이트, 클릭으로 이동
- 막대 종류와 방향 선택, hover 미리보기 (설치 불가 위치는 빨간색)
- 철거 도구 사용, 임시 막대 남은 턴 표시
- 현재 턴, 남은 막대 개수, 최단 경로 길이 표시(켜고 끄기), 무르기, 새 게임

### 세그먼트 3: AI 상대

- 평가 함수: 상대 최단 경로 길이 − 내 최단 경로 길이
- 미니맥스 + 알파베타 가지치기 (깊이 2~3)
- 양쪽 최단 경로 근처로 막대 후보를 좁혀 탐색량 줄이기
- 사람 대 사람 / 사람 대 AI 선택

### 세그먼트 4: 온라인 대전

- 서버에 Socket.IO 연결, 방 코드로 방 생성과 입장
- 서버에서 같은 로직으로 수를 다시 검증
- 연결 끊김 처리

### 세그먼트 5: 확장 규칙

- 보드 크기 선택 (7×7, 11×11)
- 안개 모드
- 4인 모드
- 기보 저장

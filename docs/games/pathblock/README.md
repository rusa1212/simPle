# 막대 길막

막대로 상대의 길을 막는 보드게임이다. 보드 양 끝에서 출발해 상대편 끝 줄에 먼저 도착하면 이긴다.
자기 차례에는 말을 움직이거나, 막대를 설치하거나, 철거 도구로 상대 막대를 치울 수 있다.

- 주소: `#/games/pathblock`
- 문서: [규칙 (구현 기준)](rules.md) · [기획서와 개발 순서](design.md)

## 규칙 요약

- 한 턴에 하나만 한다: 말 이동(상하좌우 1칸) / 막대 설치 / 철거 도구 사용
- 바로 옆에 상대 말이 있으면 뛰어넘고, 그 뒤가 막혀 있으면 대각선으로 비켜 간다.
- 막대는 겹치거나 십자로 교차할 수 없고, 어느 쪽이든 목표 줄로 가는 길을 완전히 막을 수 없다.

| 종류 | 길이 | 개수 (2인 9×9) | 특징 |
|---|---|---|---|
| 일반 막대 | 2칸 | 6 | 영구 |
| 긴 막대 | 3칸 | 2 | 영구 |
| 임시 막대 | 2칸 | 2 | 6수(양쪽 합산)가 지나면 사라짐 |
| 철거 도구 | - | 1 | 상대가 설치한 막대 1개 제거 |

확장 규칙(보드 크기 7×7·9×9·11×11, 4인 모드, 안개 모드)과 인원·보드별 개수는 [rules.md](rules.md)에 있다.

## 기능

- 같은 화면에서 번갈아 두는 2인·4인 대전
- AI 상대 (보통·어려움). 사람은 A를 맡고, AI는 나머지를 Web Worker에서 계산한다.
- 이동 가능한 칸 하이라이트, 막대 설치 미리보기 (설치할 수 없는 자리는 빨간색)
- 남은 막대 개수, 임시 막대 남은 턴, 최단 경로 길이 표시
- 무르기, 새 게임, 기보 저장·불러오기 (JSON)

## 조작

| 키 | 동작 |
|---|---|
| `R` | 막대 방향 바꾸기 (가로/세로) |
| `Esc` | 말 이동 모드로 돌아가기 |
| `Ctrl+Z` | 무르기 |

## 코드 위치

```
shared/game/                 게임 로직과 AI (순수 TypeScript, node:test)
  game.ts                      상태 생성, 수 검증과 적용
  moves.ts                     말 이동과 점프
  walls.ts                     막대 겹침·교차 판정
  path.ts                      BFS 최단 경로
  ai.ts                        평가 함수, 미니맥스 + 알파베타, 막대 후보 좁히기
  config.ts                    막대 개수 등 기본 수치
  variants.ts                  확장 규칙 (보드 크기, 4인, 안개)
  record.ts                    기보 형식, 저장과 복원
client/src/games/pathblock/  화면 (React + SVG)
  PathBlockGame.jsx            게임 화면, 상태와 기록 관리
  components/                  보드, 플레이어 패널, 도구 막대
  ai.worker.js                 AI 계산용 Web Worker
```
